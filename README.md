# ESP32-S3-RFID-Door-Lock
ESP32 Master Course Episode 11 — RFID door lock with an MFRC522 reader, OLED display, voice prompts, and a 12 V solenoid.
## Episode 11 Project Files

- [Download the Arduino sketch](RFID_Door_Lock.ino)
- [View the wiring diagram (PDF)](RFID%20ACCESS%20CONTROL.pdf)

Before uploading the sketch to your ESP32-S3, replace the example
`ALLOWED_UID` with the UID of your authorized RFID card.
